Metric Index

Model Field Definitions

Quick reference for the columns, filters, confidence labels, parlay estimates, and correlation signals used throughout the board.

Core Projection Metrics

Projected Hits
Model-estimated hit expectation for the player based on available projection inputs. This is not a guaranteed result.
Hit Score
A blended model score intended to rank hitter opportunity and strength for the current matchup.
Last 30 1+ Hit Rate
Recent percentage or rate showing how often a player recorded at least one hit across the recent sample when available.
Batting Order
Expected or confirmed lineup position. Earlier lineup spots generally receive more plate appearance opportunity.

Confidence & Grades

Grade A
Highest board tier. Displayed when the model output provides an A grade or when derived thresholds meet the strongest available criteria.
Grade B
Strong but below Grade A. Usually reflects a favorable blend of score, projection, and recent profile.
Grade C
Playable or watch-list tier depending on user thresholds. Less aggressive than A or B.
Confidence Score
Numeric confidence value from the JSON when available. If missing, the UI estimates it from grade, Hit Score, Projected Hits, and recent hit rate.
Derived Grade
If the JSON does not include a confidence grade, the UI estimates one from Hit Score, Projected Hits, and recent hit-rate fields.

Filter Board

Minimum Hit Score
Filters out players below the selected model score threshold.
Minimum Projected Hits
Filters out players below the selected projected-hit threshold.
Parlay Eligible
Limits the board to pre-game players with enough estimated probability to be considered by the parlay maker.
Season / Career BA vs Hand
Filters hitter batting average against the opposing pitcher handedness when those fields are present in the JSON. These raw fields are intentionally kept out of the main board and used inside lean/value logic.
Pitcher BAA vs Hand
Filters opposing pitcher batting average allowed against the hitter handedness. Raw pitcher BAA is used in matchup/value logic instead of being displayed as a main board column.
Hide Started Games
Hides games marked started, live, final, in-progress, or frozen. These rows remain in the data but are removed from view.

Correlation Board

Correlation Signal
A model or fallback pattern combining multiple thresholds, such as Hit Score plus Projected Hits.
Sample
Number of matching rows or historical opportunities when the model output provides that data.
Hit Rate
Historical or model-provided success rate if included in the JSON. If unavailable, the UI displays an estimated current-board hit rate based on matching player probabilities.
Signal Score
A ranking score used to sort available signals. Higher scores appear earlier.

Parlay Maker

Estimated Leg Probability
UI-estimated probability using score, projection, recent hit rate, and grade. This is a model estimate, not sportsbook probability.
All-Hit Probability
Estimated combined probability that every selected leg records a hit. It assumes legs are independent unless your model data says otherwise.
Fair Value
Estimated fair American odds and multiplier based on model probability. It is not a betting recommendation or guaranteed edge.
Model-Generated Parlays
Automatically built from filtered, pre-game eligible rows ranked by model strength.

Data & Status Fields

Last Model Run
Timestamp pulled from the JSON using common fields like last_run_et, generated_at_et, timestamp, or nested run-time fields.
Pre-game
Game has not been marked started by the available data fields.
Frozen/Started
Game appears to be started, live, final, in-progress, or frozen based on the JSON status fields.
Sortable / Frozen Board
Today’s Board supports clickable column sorting and keeps the player-name column frozen while scrolling horizontally.
Export Visible CSV
Exports only the rows currently visible after filters are applied.

Suggested JSON Timestamp Keys

Preferred Field
Use last_run_et when possible, for example: "last_run_et": "2026-05-16 3:05 PM ET".
Also Supported
generated_at_et, model_run_time_et, last_updated_et, timestamp, generated_at, updated_at, and common camelCase versions.
Nested Fields
The UI also searches nested metadata objects for run, generated, updated, or timestamp-like keys.

Model Value Columns

Lean Type
The strongest UI-generated lean category for the row: Core, Rising, Matchup, Volume, Watchlist, or Standard.
Model Value
A UI-generated value score that blends confidence, estimated leg probability, Hit Score, Projected Hits, grade, and lean strength.
Fair Odds
Estimated fair American odds based on the UI-estimated hit probability. This is not a sportsbook line.
Value Reason
Plain-English summary of why the row is surfacing, without showing raw data-heavy split columns on the main board.

Daily Lean Board

Core Leans
Players closest to the high-confidence profile using Grade, Confidence Score, Hit Score, Projected Hits, and estimated leg probability. If a category has no strict matches, fallback rows are shown so the UI never displays an empty lean box.
Rising Leans
Players who may not be Grade A but are surfacing through recent form, projection, score range, or lineup position.
Matchup Leans
Players with hitter batting-average strength against pitcher hand and/or a favorable opposing pitcher BAA allowed profile.
Volume Leans
Players with stronger plate appearance opportunity based primarily on lineup position and projected hit volume.
Watchlist Leans
Interesting non-core names with one or two strong supporting signals. These are discovery signals, not automatic plays.

Important Usage Notes

Model Estimates
All rankings, filters, probabilities, and grades are estimates based on available data and assumptions.
Lineups
A missing or unconfirmed batting order can reduce confidence. Confirm lineups separately before relying on any row.
Late Changes
Scratches, pitching changes, weather, lineup changes, and data delays can materially change projections.
